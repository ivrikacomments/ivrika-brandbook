# ИВРИКА. Брендбук

Версия 2.1 от 1 ноября 2026 года. 28 страниц.

- [HTML-версия брендбука](index.html)
- [Четыре примера презентационных слайдов](slides.html)

Визуальная концепция: «Солнечный Израиль», принятая кудрявая пара в кафе, сухая печать и светлая средиземноморская палитра.

Соцсети: Rubik. Сайт: Ubuntu для заголовков, Montserrat для основного текста. Символы проекта: гранат и апельсин.

HTML использует локальные изображения и шрифты из `assets/`. Чтобы открыть документ без GitHub, скачайте репозиторий целиком и откройте `index.html` в браузере. `slides.html` содержит редактируемые текстовые элементы и четыре примера слайдов.

Исходные изображения сохранены без изменений. Лицензии шрифтов находятся в `assets/fonts/`. Документ не содержит внешних скриптов и не требует сборки.
